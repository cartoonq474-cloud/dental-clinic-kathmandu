# Dental Website Design Skill

This skill provides guidelines and templates for developing the BrightSmile Dental Clinic website.

## Page Hierarchy & Structure
1. **Home**: Hero section, key metrics (patients served, years established), core services preview, dentist profiles, testimonials.
2. **Services**: Detailed sections for:
   - Teeth Whitening
   - Dental Implants
   - Root Canal
   - Orthodontics
3. **Appointment Booking**: A clean form collecting patient name, phone, desired service, date, and preferred time slot.
4. **Contact & Location**: Interactive map preview, operating hours, phone, email, and address info.

## Coding Patterns
- Always build semantic structures.
- Ensure all input fields have clear labels and validation states.
- Follow premium UX styling principles: smooth hover states, responsive layouts, medical-themed illustrations, or clean icon sets.
