## Technology Stack & Guidelines
1. **Core**: Use HTML for structure and Javascript for logic.
2. **Styling**: Use Vanilla CSS for layouts and styling. Avoid TailwindCSS unless explicitly requested by the user.
3. **SEO Best Practices**:
   - Compelling meta descriptions and search-engine optimized title tags.
   - Use correct HTML5 semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
   - Use a single `<h1>` per page.
   - Descriptive unique IDs for all key interactive elements.
4. **Design Aesthetics**: Keep the UI modern, clean, and highly responsive. Use card layouts, smooth transitions, and premium animations.
